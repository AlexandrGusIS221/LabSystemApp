# 🩺 LabSystemApp — Медицинская информационная система

**LabSystemApp** — это многоуровневое WPF-приложение для автоматизации лабораторной диагностики. Система управляет пользователями, заказами, результатами анализов и бухгалтерией, поддерживая роли: пациент, лаборант, администратор и бухгалтер.

---

## ✨ Основные возможности

### 🔑 Авторизация (`AuthWindow`)
- Вход по логину, паролю и капче
- Блокировка после нескольких неудачных попыток
- Логирование сессий с фиксацией IP
- Роутинг пользователей по ролям

### 🙍‍♂️ Пациент (`PatientWindow`)
- Просмотр личных результатов анализов
- Удобный интерфейс с таблицей данных
- Отображение профиля и роли
- Режим только для чтения

### 💸 Бухгалтерия (`AccountantWindow`)
- Просмотр заказов по страховым компаниям
- Фильтрация по дате и компании
- Экспорт отчётов в `.txt`
- Генерация счетов для заказов
- Хранение истории отчётов

### 🔬 Лабораторные анализы (`LabAnalysis`)
- Список активных и ожидающих исследований
- Автоматический выбор анализатора по услуге
- Отправка данных на анализ через API (JSON, HTTP)
- Асинхронная обработка с таймером прогресса
- Проверка отклонений (в 5 раз от нормы) с подтверждением
- Обновление результатов лаборантом

### 📋 Заказ исследований (`LabOrderWindow`)
- Создание новых заказов
- Выбор пациента и услуг
- Генерация штрихкодов и экспорт в PDF
- Расчёт стоимости заказа
- Сохранение в базу данных

### ➕ Регистрация пациента (`AddPatientWindow`)
- Добавление пользователей и пациентов
- Проверка логина, пароля и email
- Загрузка фото в Assets
- Сохранение в таблицы `users` и `patients`

### 🛠️ Администрирование (`AdminWindow`)
- Управление пользователями, ролями, анализаторами
- Добавление сотрудников с фото
- История входов в систему
- Просмотр услуг по анализатору
- Визуализация данных (графики ScottPlot)
- Поиск по логинам и истории
- Массовое хеширование паролей

---

## 🗄️ Структура базы данных

| Таблица             | Описание                              |
|---------------------|---------------------------------------|
| `users`             | Зарегистрированные пользователи       |
| `orders`            | Заказы на исследования                |
| `services`          | Лабораторные услуги                   |
| `analyzers`         | Медицинские анализаторы               |
| `analyzerWorks`     | История выполнения анализов           |
| `accountantReports` | Отчёты для страховых компаний         |
| `sessionHistories`  | История входов и сессий               |

---

## 🛡️ Безопасность
- Хеширование паролей через `PasswordHelper`
- Капча и блокировка при неудачных входах
- Логирование всех авторизаций с IP

---

## 🛠️ Технологии
- **Frontend**: WPF (MVVM-подобная архитектура)
- **Backend**: Entity Framework, MSSQL
- **Интеграция**: `HttpClient`, `WebRequest` для связи с LIMS-анализаторами
- **Асинхронность**: Обработка услуг с `DispatcherTimer` для UI

---

## 🚀 Установка и запуск

1. Настройте базу данных MSSQL.
2. Запустите `LIMSAnalyzers.exe` (эмулятор анализаторов).
3. Соберите и запустите WPF-приложение.
4. Войдите через тестовый аккаунт или зарегистрируйте нового пациента.
