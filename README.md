# 🧪 LabSystemApp — Медицинская информационная система

Многоуровневое клиентское приложение на WPF для автоматизации лабораторной диагностики, управления пользователями, заказами, результатами анализов и бухгалтерией. Система поддерживает основные роли: **Пациент**, **Лаборант**, **Администратор** и **Бухгалтер**.

---

## ✨ Основные возможности

### 🔐 Авторизация (`AuthWindow`)
- Безопасный вход с логином, паролем и капчей.
- Блокировка аккаунта после нескольких неудачных попыток.
- Логирование сессий и IP-адресов.
- Перенаправление по ролям: администратор, лаборант, пациент, бухгалтер.

### 👤 Пациент (`PatientWindow`)
- Просмотр собственных результатов анализов в удобном DataGrid.
- Отображение профиля и роли.
- Только режим чтения для простоты и безопасности.

### 🧾 Бухгалтерия (`AccountantWindow`)
- Просмотр заказов с фильтрацией по страховым компаниям и датам.
- Формирование и экспорт отчётов в `.txt`.
- Генерация счетов по выбранным заказам.
- Хранение истории отчётов.

### 🧬 Лабораторные анализы (`LabAnalysis`)
- Отображение активных и ожидающих исследований.
- Автоматический выбор анализатора на основе услуги.
- Отправка данных на анализ через API (JSON по HTTP).
- Асинхронная обработка с таймером прогресса.
- Проверка отклонений от нормы (в 5 раз) с ручным подтверждением.
- Обновление результатов после проверки лаборантом.

### 🧾 Заказы исследований (`LabOrderWindow`)
- Создание новых заказов.
- Выбор пациента и услуг.
- Генерация штрихкодов и сохранение в PDF.
- Расчёт общей стоимости.
- Сохранение заказов в базу данных.

### ➕ Регистрация пациента (`AddPatientWindow`)
- Регистрация пользователей и пациентов.
- Проверка корректности логина, пароля и email.
- Загрузка и сохранение фото в папку `Assets`.
- Сохранение данных в таблицы `users` и `patients`.

### 🛠 Администрирование (`AdminWindow`)
- Управление пользователями, ролями и анализаторами.
- Добавление сотрудников с фотографиями.
- Просмотр истории входов и работы анализаторов.
- Визуализация данных с помощью графиков **ScottPlot**.
- Поиск по логинам и истории.
- Массовая генерация хешей паролей.

## 📦 Технические детали
- **Фреймворк**: WPF с архитектурой, близкой к MVVM.
- **База данных**: Entity Framework с MSSQL.
- **Интеграция API**: `HttpClient` и `WebRequest` для связи с LIMS-анализаторами.
- **Асинхронность**: Эффективная обработка операций.
- **Обновление UI**: `DispatcherTimer` для таймеров и прогресс-баров.

### 📂 Структура базы данных
| Таблица             | Назначение                          |
|---------------------|-------------------------------------|
| `users`             | Зарегистрированные пользователи     |
| `orders`            | Заказы на исследования             |
| `services`          | Доступные лабораторные услуги       |
| `analyzers`         | Медицинские анализаторы            |
| `analyzerWorks`     | История работы анализаторов         |
| `accountantReports` | Отчёты для страховых компаний      |
| `sessionHistories`  | История входов и сессий            |

### 🔒 Безопасность
- Хеширование паролей с помощью `PasswordHelper`.
- Капча и блокировка при неудачных попытках входа.
- Полная фиксация авторизаций с IP-адресами.

## 🚀 Запуск

### Требования
- Настроенная база данных MSSQL.
- Установленный SQL Server Management Studio (SSMS).
- Файл `.bacpac` для импорта базы.

### Инструкция по запуску
1. **Настройка базы данных**:
   - Импортируйте `.bacpac` файл (см. ниже).
2. **Запуск эмулятора анализаторов**:
   - Запустите `LIMSAnalyzers.exe`.
3. **Сборка и запуск**:
   - Соберите и запустите WPF-приложение.
4. **Вход**:
   - Используйте тестовый аккаунт или зарегистрируйте нового пациента.

## 📥 Импорт файла `.bacpac` в SQL Server

### 🛠 Требования
- SQL Server Management Studio (SSMS, желательно последняя версия).
- SQL Server (локальный или удалённый).
- Файл `.bacpac`.

### 📌 Шаги
1. Запустите SSMS и подключитесь к серверу.
2. В **Object Explorer**:
   - Щёлкните правой кнопкой мыши на папке **Databases**.
   - Выберите **Import Data-tier Application**.
3. В мастере импорта:
   - Нажмите **Next**.
   - Выберите **Import from local disk**.
   - Нажмите **Browse** и найдите файл `.bacpac`.
   - Нажмите **Next**.
4. Укажите параметры базы данных:
   - Введите имя новой базы.
   - При необходимости задайте пути для файлов `.mdf` и `.ldf`.
   - Убедитесь, что у SQL Server есть права на указанные пути.
5. Нажмите **Next**, проверьте сводку и нажмите **Finish** для импорта.

### ✅ После импорта
- Новая база появится в разделе **Databases**.
- Можно сразу выполнять запросы и работать с таблицами.

### 📝 Примечания
- При ошибке «Access denied» запустите SSMS от имени администратора.
- Файлы `.bacpac` нельзя прикрепить напрямую, как `.mdf`.
- Поддерживаются SQL Server и Azure SQL.

---

## 🧩 Что такое `.bacpac`?
`.bacpac` — это архив базы данных SQL Server, содержащий схему и данные. Удобен для резервного копирования, миграции или переноса баз.

---

## 🌟 Почему LabSystemApp?
LabSystemApp упрощает лабораторные процессы, повышает безопасность и предоставляет удобные интерфейсы для каждой роли. От самостоятельного доступа пациентов до мощных инструментов администрирования — это комплексное решение для современной диагностики.
